# 여행 가자 (Trip)

같이 가는 여행 준비 — 여행을 만들고 **링크만 단톡방에 보내면** 다 같이 보고 고치는 페이지. (2026-10-09, 캠핑 구글 시트에서 출발)

- 페이지: https://benny3s.github.io/trip/
- 디자인·공용 코드: 약속 잡자(`/when/`)의 `ui.css`·`core.js` 를 같이 씀 → 그쪽을 고치면 `index.html` 의 `?v=` 도 올리기
- 저장: Firebase `benny-apps` Firestore. 규칙은 `benny3s/benny-apps` 의 `firestore.rules` '여행 가자' 부분

## 세 탭

| 탭 | 하는 일 |
|---|---|
| 📢 공지·일정 | **일정·메뉴·담당 한 타임라인** — 날짜별로 시각 또는 출발 전·아침·점심·저녁·밤, 내용, 담당(우리 팀 초록), 할 일. 공지 카드는 예약 정보처럼 안 바뀌는 것만. 누구나 고침 |
| ✅ 준비물 | 버튼 하나 — 줄을 한 번 누르면 **준비**(짐 쌈), 한 번 더 누르면 **완료**(차에 실음), 또 누르면 처음으로. ‘각자’ 준비물은 팀마다 따로, 📍 현장은 한 번에 완료. 수정은 ✎ 준비물 수정 |
| 💰 정산 | 지출 바로 적기(낸 팀 + 몫), 팀별 쓴 돈·부담, **보낼 돈 자동 계산**, ‘보냈어요’ = 송금 기록, 📋 정산 공지 복사 |

## 구조

| 경로 | 내용 |
|---|---|
| `tripIdx/{pid}` | 링크 `?t=pid` (무작위 20자) — 이름·시작 날짜. 목록 조회는 막힘 (`locked` 는 규칙 때문에 남겨 둔 칸, 늘 false) |
| `trips/{K}` | K = `sha256(pid + ":")` — pid·이름·날짜·장소·주소·연락처·`teams[{id,name,people,bank}]` (화면에선 '사람' — 이름 하나 = 정산 하나, 부부·가족은 '베니네'처럼)·`cats` |
| `trips/{K}/items/{id}` | 준비물 `{cat,name,who[],memo,ord,st}` — `st[팀id 또는 "_"]` = 0 아직 · 1 준비 · 2 완료 — 열쇠는 담당자마다(모두 = 전원), 담당 미정만 "_" 하나 |
| `trips/{K}/money/{id}` | `{kind exp/pay, title, amt, payer, split{팀: 몫}, memo}` — 송금 기록은 kind pay, split = {받은 팀: 1} |
| `trips/{K}/notes/{id}` · `plan/{id}` | 공지 카드 · 일정 한 줄 `{date, time, text, who[], memo, place}` (place = 식당·장소, 누르면 네이버 지도 검색) |

- **링크로만 들어옴** (2026-11-03 PIN 없앰): 링크를 아는 사람은 보기·고치기·지우기까지 된다. 복구는 매일 내려받는 자료 (`benny-apps/backup_data.py`).
- **관리자 목록**: 포털 관리자로 로그인한 기기는 첫 화면에 전체 여행이 보인다 (`adminIdx`). 관리자 기기에서 만든 여행은 바로, 친구가 만든 여행은 매일 백업 때 들어온다.
- **레퍼런스**: 기본 목록 ⛺ 캠핑 · 🚗 국내 여행 · ✈️ 해외 여행 (코드의 `TEMPLATES`) + 이 기기에서 연 지난 여행. 새 여행 만들 때 고르거나, ✎ 목록 고치기 → 📋 기본 목록에서 추가 (동그란 이름 버튼 — 초록 ✓ 가져올 것, 회색 ✓ 이미 있음).
- 정산: 몫은 소수로 더하고 팀 잔액에서 한 번만 반올림(±1원은 |잔액| 큰 팀) → 큰 빚부터 큰 받을 돈에 맞추는 방식으로 송금 목록.
- 누가(who): 사람 이름 + 특별 4개 `공통` `각자` `마트` `현장`.
- 이 기기에서 연 여행·우리 팀은 localStorage (`tr_mine`, `tr_me:<tid>`).
